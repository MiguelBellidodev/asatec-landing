# ASATEC Landing

Static landing page for ASATEC technical registries.

## Structure

- `index.html`: page markup
- `assets/css/main.css`: stylesheet entry point
- `assets/css/utils/`: shared base, color, and font styles
- `assets/css/includes/`: section-level styles
- `assets/js/`: page behavior
- `assets/img/`: images
- `assets/data/`: site data
